# CV / JD Matching Agent

An AI agent that automatically matches a candidate's CV against a job description and generates a tailored gap analysis report.

**Built by Saksham Kapahi — October 2026**

## What it does

- Extracts required and preferred skills from any job description
- Scores the candidate profile across skills, experience, education and certifications
- Calculates an overall match percentage and fit rating
- Generates specific CV tailoring recommendations

## Demo output

Running against EY Senior Consultant – Business Transformation (Ireland):

- Overall match: 85% — Strong Fit
- Skills matched: Python, SQL, Salesforce, PRINCE2, Power BI, Stakeholder Management
- Certifications: PRINCE2 Practitioner ✓, Salesforce Administrator ✓
- Education: MSc Business Management, DCU ✓
